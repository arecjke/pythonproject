# Homework

## Описание:

*Homework* - проект, содержащий в себе задания из домашней работы.

## Установка:

1. Клонируйте репозиторий:
```
git clone https://github.com/arecjke/pythonproject
```
2. Установите зависимости:
```
pip install -r requirements.txt
```
## Использование:

1. Откройте проект в удобном вам редакторе(желательно pyCharm).
2. Создайте новый проект и начните добавлять задачи.
3. Назначайте сроки выполнения и приоритеты для задач, чтобы эффективно управлять проектами.


## Тесты:

1. Откройте проект в удобном вам редакторе.
2. Откройте каталог "tests".
3. Выберите нужный вам модуль с тестами.
4. Запустите тесты, используя 
```
pytest test_your_module.py
```
(вместо "your_module" подставьте название нужного модуля).
5. Для просмотра покрытия тестами используйте ``` pytest --cov=src.your_module --cov-report=term-missing test_your_module.py```.
   (Аналогично 4-му пункту, замените "your_module").
